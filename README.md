# Agent Skills

A collection of reusable agent skills organized by category. Each skill can be installed on its own.

## Project Planning

[Estimator](project-planning/estimator/SKILL.md) turns a software brief into a client-ready estimate of effort, delivery time, and cost.

```bash
npx skills add umairx97/agent-skills --skill estimator
```

To see the skills available in this repository, run:

```bash
npx skills add umairx97/agent-skills --list
```
